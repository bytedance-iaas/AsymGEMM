## SM90 vs SM100 Threading Model Comparison

### SM100 Asym Threading (what the files currently have, WRONG for SM90):
```
warp 0 (1 thread elect): TMA loader for A and B
warp 1 (1 thread elect): UMMA issuer (issues tcgen05 instructions that write to TMEM)
warps >= kNumNonEpilogueThreads/32: epilogue warps (TMEM → SMEM → HBM via TMA store)
```
- Accumulation lives in **Tensor Memory (TMEM)** — a hardware register file absent on SM90
- UMMA instructions are issued by a **single warp** (not a warp-group)
- The TMEM pipeline enables overlap between UMMA and epilogue

### SM90 Asym Threading (what we must implement):
```
warp-group >= kNumMathThreads/32  (128 threads): TMA warp-group — loads A (staged) and B (single slot)
warp-group < kNumMathThreads/32   (128 or 256 threads): math warp-group(s) — WGMMA + epilogue
```
- Accumulation lives in **registers** (`float accum[WGMMA::kNumAccum]`)
- WGMMA instructions require a full **warp-group (128 threads)** to issue them
- No TMEM stages; after WGMMA, the math warp-group writes directly to `smem_cd`, then issues TMA store

### SM90 Thread Counts:
- For `BLOCK_M = 64`: `kNumMathThreads = 128` (1 WG handles 64 rows, M = WGMMA::M = 64)
- For `BLOCK_M = 128`: `kNumMathThreads = 256` (2 WGs handle 64 rows each, combined = 128 rows)
- `kNumTMAThreads = 128` always (1 TMA warp-group)

### TMA warp-group (outer loop structure)

```cpp
if (warp_idx >= kNumMathThreads / 32) {
    cutlass::arch::warpgroup_reg_dealloc<kNumTMARegisters>();

    // Only 1 thread in the TMA WG does actual TMA work
    if (warp_idx == kNumMathThreads / 32 + 2 && cute::elect_one_sync()) {
        for (int k = 0; k < block_k; ++k) {
            uint32_t k_idx = k * BLOCK_K;
            // Wait for math WG to release B smem from previous iteration
            empty_barriers_b[0]->wait(phase_b ^ 1);
            // Load B tile (K-major: shape [BLOCK_K, LOAD_BLOCK_N])
            tma_copy<BLOCK_K, LOAD_BLOCK_N, kSwizzleBMode, cutlass::bfloat16_t, false>(
                &tensor_map_b, full_barriers_b[0], smem_b[0], k_idx, n_idx, kNumMulticast, 0);
            if (is_leader_cta)
                full_barriers_b[0]->arrive_and_expect_tx(SMEM_B_SIZE_PER_STAGE);

                full_barriers_b[0]->arrive(0u);

            for (auto m = m_start; m < m_end; advance_pipeline(m)) {
                uint32_t m_idx = compute_m_idx(m, ...);
                // Wait for math WG to release this A stage
                empty_barriers[stage_idx]->wait(phase ^ 1);

                    full_barriers[stage_idx]->arrive_and_expect_tx(SMEM_A_SIZE_PER_STAGE * kNumMulticast);
                else
                    full_barriers[stage_idx]->arrive(0u);
            }
        }
        // Drain remaining empty waits if TMA multicast > 1
    }
```

### Math warp-group (the main loop)

```cpp
} else {
    cutlass::arch::warpgroup_reg_alloc<kNumMathRegisters>();

    const auto math_wg_idx = __shfl_sync(0xffffffff, threadIdx.x / 128, 0);
    // math_wg_idx = 0 for WG covering rows [0, 64)
    // math_wg_idx = 1 for WG covering rows [64, 128)  (when kNumMathThreads==256)

    // Build GMMA descriptors (addresses rebased each stage/block):
    constexpr uint32_t BLOCK_ATOM_K = BLOCK_K / kNumStagesPerMerge;
    auto a_desc = make_gmma_desc<kMajorA, LOAD_BLOCK_M, BLOCK_ATOM_K, kSwizzleAMode>(
                      smem_a[0], math_wg_idx * WGMMA::M, 0);
    auto b_desc = make_gmma_desc<kMajorB, LOAD_BLOCK_N, BLOCK_ATOM_K, kSwizzleBMode>(
                      smem_b[0], 0, 0);
    const uint32_t a_desc_lo = __shfl_sync(0xffffffff, a_desc.reg32_[0], 0);
    const uint32_t b_desc_lo = __shfl_sync(0xffffffff, b_desc.reg32_[0], 0);

    for (int k = 0; k < block_k; ++k) {
        // Wait for B to be loaded
        full_barriers_b[0]->wait(phase_b);
        phase_b ^= 1;

        for (auto m = m_start; m < m_end; advance_pipeline(m)) {
            // Per-(K,M) block accumulation (NOT across K blocks)
            float accum[WGMMA::kNumAccum * (BLOCK_M / WAVE_BLOCK_M)] = {};

            // Wait for A to be loaded
            full_barriers[stage_idx]->wait(phase);

            // WGMMA fence + issue
            const auto a_desc_base = a_desc_lo + stage_idx * (SMEM_A_SIZE_PER_STAGE / 16);
            const auto b_desc_base = b_desc_lo;

            for (uint32_t i = 0; i < WGMMA::kNumAccum * (BLOCK_M / WAVE_BLOCK_M); ++i)
                warpgroup_fence_operand(accum[i]);
            warpgroup_arrive();
            for (uint32_t local_idx = 0; local_idx < BLOCK_M / WAVE_BLOCK_M; ++local_idx) {
                auto shifted = accum + WGMMA::kNumAccum * local_idx;
                for (uint32_t kk = 0; kk < BLOCK_K / WGMMA::K; ++kk) {
                    const uint32_t atom_k = kk * WGMMA::K / BLOCK_ATOM_K;
                    a_desc.reg32_[0] = advance_gmma_desc_lo<kMajorA, LOAD_BLOCK_M, BLOCK_ATOM_K, kSwizzleAMode, nv_bfloat16>(
                        a_desc_base, local_idx * WAVE_BLOCK_M, (kk * WGMMA::K) % BLOCK_ATOM_K,
                        atom_k * LOAD_BLOCK_M * BLOCK_ATOM_K);
                    b_desc.reg32_[0] = advance_gmma_desc_lo<kMajorB, LOAD_BLOCK_N, BLOCK_ATOM_K, kSwizzleBMode, nv_bfloat16>(
                        b_desc_base, 0, (kk * WGMMA::K) % BLOCK_ATOM_K,
                        atom_k * LOAD_BLOCK_N * BLOCK_ATOM_K);
                    WGMMA::wgmma(a_desc, b_desc, shifted, kk);
                }
            }
            warpgroup_commit_batch();
            for (uint32_t i = 0; i < WGMMA::kNumAccum * (BLOCK_M / WAVE_BLOCK_M); ++i)
                warpgroup_fence_operand(accum[i]);
            warpgroup_wait<0>();

            // Release A smem stage
            empty_barrier_arrive(stage_idx);

            // Epilogue: write to smem_cd then issue TMA store (or TMA reduce-add)
            // [see epilogue section below]
        }

        // Release B smem slot
        empty_barriers_b[0]->arrive();
    }
}
```

### Epilogue (inside math warp-group, after WGMMA)

The epilogue follows `sm90_bf16_gemm.cuh`'s STSM pattern for BF16, or `st.shared` for FP32:

```cpp
// --- Within math warp-group, after WGMMA ---

// Wait for previous TMA store to finish (pipeline the smem_cd double-buffer)
if (warp_idx % 4 == 0 && cute::elect_one_sync())
    cute::tma_store_wait<kNumTMAStoreStages - 1>();
cutlass::arch::NamedBarrier::sync(STORE_BLOCK_M, 0);

// Write accumulator to smem_cd using STSM (BF16) or st.shared (FP32)
constexpr uint32_t WGMMA_M_PER_WARP = WGMMA::M / 4;  // 16 rows per warp
for (uint32_t local_idx = 0; local_idx < BLOCK_M / WAVE_BLOCK_M; ++local_idx) {
    auto m_offset = local_idx * WAVE_BLOCK_M;
    auto shifted = accum + WGMMA::kNumAccum * local_idx;
    if constexpr (cute::is_same_v<cd_dtype_t, cutlass::bfloat16_t>) {
        // Use STSM with swizzled addresses (same pattern as sm90_bf16_gemm.cuh lines 298-338)
        for (auto i = 0; i < WGMMA::kNumAccum / 4; ++i) {
            constexpr uint32_t kNumBankGroupBytes = 16;
            auto atom_offset = i / (STORE_BLOCK_N / 8);
            auto in_atom_offset = i % (STORE_BLOCK_N / 8);
            auto bank_group_index = in_atom_offset + lane_idx * (kSwizzleCDMode / kNumBankGroupBytes);
            constexpr bool kHasShortcut = (kSwizzleCDMode / kNumBankGroupBytes) == 8;
            auto row = kHasShortcut ? (in_atom_offset / 8 + lane_idx) : (bank_group_index / 8);
            auto col = kHasShortcut ? (in_atom_offset) : (bank_group_index % 8);
            col ^= row % (kSwizzleCDMode / 16);
            auto smem_ptr = reinterpret_cast<uint8_t*>(smem_cd[tma_stage_idx]) +
                (warp_idx % 4) * (WGMMA_M_PER_WARP * kSwizzleCDMode) +
                m_offset * kSwizzleCDMode +
                atom_offset * STORE_BLOCK_M * kSwizzleCDMode +
                row * (kNumBankGroupBytes * 8) + col * kNumBankGroupBytes;
            SM90_U32x2_STSM_N<nv_bfloat162>::copy(
                __float22bfloat162_rn({shifted[i*4+0], shifted[i*4+1]}),
                __float22bfloat162_rn({shifted[i*4+2], shifted[i*4+3]}),
                smem_ptr);
        }
    } else {
        // FP32: use st.shared (same as sm90_bf16_gemm.cuh lines 344-354)
        auto smem_d_0 = reinterpret_cast<float2*>(smem_cd[tma_stage_idx] +
            (m_offset + (warp_idx % 4) * WGMMA_M_PER_WARP + lane_idx / 4) * STORE_BLOCK_N + (lane_idx % 4) * 2);
        for (auto i = 0; i < WGMMA::kNumAccum / 4; ++i) {
            ptx::st_shared(smem_d_0 + i * 4, {shifted[i*4+0], shifted[i*4+1]});
            ptx::st_shared(smem_d_0 + i * 4 + ..., {shifted[i*4+2], shifted[i*4+3]});
        }
    }
}
cute::tma_store_fence();
cutlass::arch::NamedBarrier::sync(STORE_BLOCK_M, 0);

// Issue TMA store (k==0) or TMA REDUCE ADD (k>0)
if (warp_idx % 4 == 0 && cute::elect_one_sync()) {
    const auto m_idx = compute_m_idx_for_output(m, ...);
    const auto n_idx_out = scheduler.n_idx;
    if (k == 0) {
        cute::SM90_TMA_STORE_2D::copy(&tensor_map_cd, smem_cd[tma_stage_idx], n_idx_out, m_idx);
    } else {
        cute::SM90_TMA_REDUCE_ADD_2D::copy(&tensor_map_cd, smem_cd[tma_stage_idx], n_idx_out, m_idx);
    }
    cute::tma_store_arrive();
}
tma_stage_idx = (tma_stage_idx + 1) % kNumTMAStoreStages;
```

Key correctness rules:
- `warp_idx` for TMA warp-group: `warp_idx >= kNumMathThreads / 32`

- `math_wg_idx = threadIdx.x / 128` (within math warp-group, not affected by TMA threads)

- NO call to `Allocator().allocate()` / `Allocator().free()` (no TMEM)
- NO `tcgen05_*` calls (SM100-specific)
- NO `umma_arrive()` calls (SM100-specific) — use `empty_barriers[s]->arrive()` directly
- `full_barriers_b[0]` init count = `kNumMulticast` (leader CTA signals via `arrive_and_expect_tx`, non-leader via `arrive(0u)`)
- `empty_barriers_b[0]` init count = `1` (math WG signals once after consuming B)
- `full_barriers[i]` init count = `kNumMulticast`
- `empty_barriers[i]` init count = `kNumTMAMulticast * kNumMathThreads / 32` — wait, for SM90: each warp in the math warp-group arrives independently (not via UMMA), so init = `1` per stage and `arrive()` is called by one thread from math WG

Actually follow the init pattern from `sm90_bf16_gemm.cuh`:
```cpp
full_barriers[i]->init(1);
empty_barriers[i]->init(kNumTMAMulticast * kNumMathThreads / 32);
```

The TMA warp-group uses `arrive_and_expect_tx(bytes)` to fill, and the math warp-group uses `arrive()` one per warp (= `kNumMathThreads/32` arrivals total) to drain.

### Changes from BF16 version

The FP8 1D1D variant adds:
1. **Scale factors**: per-token A scales (`smem_sfa`) and per-channel B scales (`smem_sfb`), loaded via TMA like the A/B tiles.

3. **FP8 data type**: A and B are `__nv_fp8_e4m3`; accumulator is `float`; output is `float` (always, for 1D1D).
4. **Scale factor TMA descriptors**: `tensor_map_sfa` and `tensor_map_sfb`.

```cpp
tma_copy<1, LOAD_BLOCK_N, 0, float, false>(
    &tensor_map_sfb, full_barriers_b[0], smem_sfb, sf_k_idx, n_idx, kNumMulticast, 0);

// Load A SFA (per M tile, per K block)  
tma_copy<1, LOAD_BLOCK_M, 0, float, false>(
    &tensor_map_sfa, full_barriers[stage_idx], smem_sfa[stage_idx], sf_k_idx, m_idx, kNumMulticast, 0);
```

Where `sf_k_idx = k_block_idx` (1D indexing into the scale factor tensor).

### Scale factor application in epilogue

After WGMMA (but before STSM/TMA store), multiply:
```cpp
// Following the pattern from sm90_fp8_gemm_1d1d.cuh lines 270-309:
const uint32_t row_idx = lane_idx / 4;
const uint32_t col_idx = lane_idx % 4;
const uint32_t r_0 = (warp_idx % 4) * 16 + row_idx;  // row in 64-row WG chunk
const uint32_t r_1 = r_0 + 8;

float scale_a_0 = ptx::ld_shared(smem_sfa[stage_idx] + r_0);
float scale_a_1 = ptx::ld_shared(smem_sfa[stage_idx] + r_1);

float2 scales_b[WGMMA::kNumAccum / 4];
for (int i = 0; i < WGMMA::kNumAccum / 4; ++i)
    scales_b[i] = ptx::ld_shared(reinterpret_cast<float2*>(smem_sfb + i * 8 + col_idx * 2));

// Then apply: final_accum[i] = scale_a_row * scale_b_col * accum[i]
for (uint32_t i = 0; i < WGMMA::kNumAccum / 4; ++i) {
    final_accum[i*4+0] += scale_a_0 * scales_b[i].x * accum[i*4+0];
    final_accum[i*4+1] += scale_a_0 * scales_b[i].y * accum[i*4+1];
    final_accum[i*4+2] += scale_a_1 * scales_b[i].x * accum[i*4+2];
    final_accum[i*4+3] += scale_a_1 * scales_b[i].y * accum[i*4+3];
}
```

Note: For the asym pattern (K-blocked), `final_accum` accumulates ACROSS K blocks in this buffer, unlike the standard GEMM. The K-level reduction is done in global memory via TMA REDUCE ADD. So the per-(K,M) WGMMA result is scaled and then contributed to global output immediately (using st.shared + TMA REDUCE ADD on HBM).

## Critical Implementation Notes

### 1. No TMEM on SM90 — register accumulation only
SM90 WGMMA accumulates into **registers**. Each thread in the 128-thread math warp-group holds `WGMMA::kNumAccum` float registers. There is no `tcgen05`, no `TMEM_LOAD`, no `Allocator` call. The full `if (warp_idx == 2) { Allocator().allocate(...) }` block must be removed.

### 2. K-reduction via TMA REDUCE ADD
Because each (K-block, M-block) tile has its own WGMMA result that is NOT accumulated across K-blocks in registers, K-reduction happens in global memory:
- `k == 0`: `SM90_TMA_STORE_2D::copy(...)` — write fresh values
- `k > 0`: `SM90_TMA_REDUCE_ADD_2D::copy(...)` — atomically add to existing values

This requires `cd_dtype_t = float` for the TMA REDUCE ADD path (BF16 reduction has limited hardware support). The BF16 output mode writes fresh every time (effectively, this asym kernel always outputs float).

### 3. Warp index mapping
```
threadIdx.x ∈ [0, kNumMathThreads):
  warp_idx ∈ [0, kNumMathThreads/32)   → math warp-group(s)
  math_wg_idx = threadIdx.x / 128       → 0 or 1

threadIdx.x ∈ [kNumMathThreads, kNumMathThreads + kNumTMAThreads):
  warp_idx ∈ [kNumMathThreads/32, (kNumMathThreads+kNumTMAThreads)/32)  → TMA warp-group
```

### 4. `smem_b` is a single slot (not staged)
B is NOT staged across M iterations. Load B once per K block, keep it in `smem_b[0]` throughout all M iterations within that K block. Only after all M iterations does the math warp-group signal `empty_barriers_b[0]->arrive()`.

### 5. Barrier initialization (must happen in TMA warp-group, warp 1 of that group)
```cpp
// In: if (warp_idx == kNumMathThreads/32 + 1 && cute::elect_one_sync())
for (i in range(kNumStages)):
    full_barriers[i]->init(1);                    // 1 arrival per fill (from TMA thread)
    empty_barriers[i]->init(kNumMathThreads / 32); // 1 per math warp (from each math warp)

full_barriers_b[0]->init(1);
empty_barriers_b[0]->init(kNumMathThreads / 32);  // all math warps arrive to release B

cutlass::arch::fence_barrier_init();
```

Wait, that's wrong for the SM90 case. In `sm90_bf16_gemm.cuh`:
```cpp
full_barriers[i]->init(1);
empty_barriers[i]->init(kNumTMAMulticast * kNumMathThreads / 32);
```
The `kNumTMAMulticast` factor handles the cluster multicast case. For H20 asym without multicast (`kNumTMAMulticast = 1`), this simplifies to `kNumMathThreads / 32`.

The empty barrier counts how many times `arrive()` is called to drain it. Each math warp calls `arrive()` once (via `lane_idx == 0 ? empty_barriers[s]->arrive() : void()`), so the count is `kNumMathThreads / 32`.

For `empty_barriers_b`, the math warp-group signals once per K block after all M tiles are processed. If kNumMathThreads=256, there are 8 math warps signaling. Init count = `kNumMathThreads / 32`.

### 6. `advance_pipeline` for asymScheduler
The `asymScheduler` gives `m_start` and `m_end` (block indices, not row indices). The `advance_pipeline` lambda increments `m` (the M block index) and advances `stage_idx` / `phase` for the A pipeline.

### 7. MGroupedMasked early exit
Keep the early-exit check from SM100:
```cpp
if constexpr (kGemmType == GemmType::MGroupedMasked) {
    if (scheduler.m_end == 0) return;
}
```
This must come AFTER `cluster_sync()` (which has been called) but BEFORE any barrier waits, to avoid deadlock.
