          designs cannot run at all (host: one copy; HBM: tiles only).

          paths; sTP is additive, gated behind NUM_GPUS=2 + new backend name.
```

Design summary (one sentence, from `agent/gb200.md`): on GB200 two GPUs share one
Grace, so replicated SP double-streams every frozen byte over two halved C2C lanes,
while classic TP — whose shards are naturally disjoint — is unusable because it needs
weights resident in HBM; AsymGEMM removes exactly that blocker, so we run tensor
parallelism whose weight shards never exist in HBM: one copy of the frozen model in
the shared Grace arena, each GPU streams its own shard's tiles over its own C2C lane,
with every streamed GEMM output-split along the shard dim of its CPU-resident operand.

```

## Why This Is A Separate Plan

This is not a kernel-variant fix and not the |1 offload plan. It changes the unit of
parallelism. Do not mix its stages into the |1 plans, and do not let it touch |1
defaults. Everything lands behind:

```text
backend name: asym_stp / asym_stp_cpuadamwds  (new; |2 only)
env master switch: ASYM_STP=1, ASYM_STP_TP_SIZE=2
guards: asym_stp* at |1 must die; asym|asym_cpuadamwds at |2 must die (unchanged)
```

Core mechanism (per streamed GEMM, the AsymGEMM-native rule):

```text
output-split every streamed GEMM along the shard dim of its CPU-resident operand
  fwd base + bwd dX (weight-streaming, cpu-right): split = TP dim of W
    -> each GPU streams a DISJOINT half of W tiles from the SAME host buffer
       (different tile offsets; kernels unchanged; no per-rank host shards)
  bwd LoRA-A grad dA = dS^T @^ X_cpu (activation-streaming, our |1 bottleneck):
    split dA by K -> each GPU streams X[:, its K-half]; dS (M x r, tiny) replicated
outputs: standard TP semantics (partial-sum reduce for row-parallel via the existing
  TMA_REDUCE_ADD epilogue + one NVLink peer copy; column-parallel outputs stay put)
```

## Stage 4: sTP Phase B — Full TP Layer Mapping (activation halving)

Purpose: convert the pair into real TP-2 so activation memory ~halves -> seq frontier.

Changes:

```text
attention: head-split across the pair (KV heads divisible by 2 — verify per model);
  flash-attn per device on full seq, half heads
MLP: gate_up column-split, down row-split; S_gate/S_up become [M, F/2] per device ->
  existing fine-grained act-offload + CPU SiLU run per device on halves (36 cores each)
residual stream: Megatron-SP-style sequence-shard between TP regions (AG before
  column-parallel, RS after row-parallel; one peer copy each at TP=2)
LoRA: B split with W, A replicated; dS allreduce (tiny); CPUAdamW unchanged on host
recompute (recomp-off-full-fg): per-device on its shards; no cross-device recompute
```
